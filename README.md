Tempest is a survival sandbox game very much like the game Terraria. I made it back in 2022 just before entering high school, and since the files have been sitting on my hard drive for so long I felt that it would be nice to re-publish it onto Github.

## Installation:
Just go to the 'Releases' page, download the .zip file for a given version, extract it, and run the .exe file.

## Controls:
- WASD to move
- Shift to roll, which is a sort of horizontal boost
- Space to jump
- LMB to break blocks
- RMB to place/interact with blocks
- C to open crafting menu
- E to open inventory
